You are working on an internal Python RPC service used by an apartment-analysis platform.

The service receives a request object describing one building and must return,
for every floor, the minimum total time required to reach that floor from floor 1.

A building has floors numbered from 1 to n.

For each i from 1 to n - 1:
- stairs[i] is the time required to move between floor i and floor i + 1 using stairs.
- elevator[i] is the time required to move between floor i and floor i + 1 using elevator.
- c is the fixed overhead paid each time an elevator ride is used.

Movement rules:
- If you move from floor x to floor y using stairs, the total cost is the sum of
stairs costs between those floors.
- If you move from floor x to floor y using elevator, the total cost is:
c + the sum of elevator costs between those floors.
- You may perform as many moves as needed.

Your task is to implement the RPC service so that for each floor i, it returns
the minimum total time required to reach floor i from floor 1.

The service contract uses Python objects rather than text I/O.

Request body:
- n: int
- elevator_overhead: int
- stairs: list[int]        # length n - 1
- elevator: list[int]      # length n - 1

Response body:
- min_times: list[int]     # length n
min_times[i - 1] is the minimum total time to reach floor i from floor 1

Constraints:
- 2 <= n <= 2 * 10^5
- 1 <= elevator_overhead <= 1000
- 1 <= stairs[k] <= 1000
- 1 <= elevator[k] <= 1000

def compute_min_times(n, elevator_overhead, stairs, elevator) -> list[int]:
    total = 0
    out = [0]
    for stairs_cost, elevator_cost in zip(stairs, elevator):
        total += min(stairs_cost, elevator_overhead + elevator_cost)
        out.append(total)
    return out
