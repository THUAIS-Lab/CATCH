To solve this problem, we need to determine if the length of the line segment connecting two points in a regular pentagon is equal to the length of another line segment connecting two different points. The key insight is that the length of a line segment between two points in a regular pentagon depends solely on the minimal number of steps between them along the perimeter of the pentagon.

### Approach
1. **Model the Pentagon**: The pentagon is labeled with vertices A, B, C, D, E in clockwise order. The distance between two points depends on the minimal number of steps required to move from one point to the other along the perimeter.
2. **Calculate Steps**: For each pair of points, compute the minimal steps required to move from one point to the other. This can be done by calculating the steps in both clockwise and counter-clockwise directions and taking the minimum.
3. **Compare Steps**: If both pairs of points have the same minimal number of steps, their line segments are of equal length.

### Solution Code
```python
# solution.py
points = ['A', 'B', 'C', 'D', 'E']

s1, s2 = input().split()
t1, t2 = input().split()

def get_min_steps(a, b):
    a_idx = points.index(a)
    b_idx = points.index(b)
    clockwise = (b_idx - a_idx) % 5
    counter = (5 - clockwise) % 5
    return min(clockwise, counter)

s_steps = get_min_steps(s1, s2)
t_steps = get_min_steps(t1, t2)

print("Yes" if s_steps == t_steps else "No")
```
